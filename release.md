Quake Bootable BR: Linux pronto para QuakeWorld direto do pendrive, com unezQuake, Chrome e Discord.

**Como usar (resumo):**
1. Baixe **todas** as partes (`.zip`, `.z01`, `.z02`...) para a mesma pasta
2. Extraia com o [7-Zip](https://www.7-zip.org/) (botão direito no `.zip` → Extrair aqui)
3. Grave o `.img` num pendrive de 8 GB+ com o [Rufus](https://rufus.ie/pt_BR/) (modo DD) ou balenaEtcher
4. Desligue o Secure Boot na BIOS
5. Dê boot pelo pendrive (F8 na ASUS, F12 na Gigabyte, F11 na MSI)

Usuário/senha: `quakeuser` / `quakeuser`

Passo a passo completo, incluindo instalação em SSD, no [README](https://github.com/tibazera/quake-bootable#readme).
